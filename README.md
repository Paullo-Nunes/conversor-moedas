# 💸 Conversor de Moedas

Uma aplicação web simples, intuitiva e responsiva para conversão de moedas em tempo real, desenvolvida como projeto de estudo de desenvolvimento web.

![Convert Money](https://raw.githubusercontent.com/seu-usuario/seu-repositorio/main/preview.png) *(Substitua com a URL da imagem de preview se desejar)*

---

## 📌 Sobre o Projeto

O **Conversor de Moedas** permite converter valores em **Real brasileiro (R$)** para diferentes moedas internacionais, como:

- 🇺🇸 **Dólar americano (USD)**
- 🇪🇺 **Euro (EUR)**
- 🇬🇧 **Libra esterlina (GBP)**
- ₿ **Bitcoin (BTC)**

A interface exibe dinamicamente as bandeiras, nomes das moedas e os valores convertidos de forma clara e visual.

---

## 🚀 Funcionalidades

- [x] Seleção de moeda de origem e moeda de destino.
- [x] Entrada de valor formatado em Real (R$).
- [x] Atualização dinâmica dos elementos visuais (bandeiras e nomes das moedas) ao alternar a opção desejada.
- [x] Layout responsivo e moderno estilizado em roxo e branco.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estruturação semântica da página.
- **CSS3**: Estilização, layout responsivo e alinhamento visual.
- **JavaScript**: Lógica de conversão de moedas e manipulação do DOM.
- **Vercel**: Hospedagem e deploy contínuo da aplicação.
